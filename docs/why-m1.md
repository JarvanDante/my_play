# M1 的作用:从「文件公开可取」到「播放即授权」

> 一句话:M1 把收费视频从「拿到链接就能永远白嫖」变成「播放是一次有时效、可撤销、可追责的授权」。
> 这是收费内容平台的安全底线,也是 M2(防盗链/统计/试看)的地基。

## M1 之前:收银台旁边的免费后门

转码产物躺在 MinIO,`play_url` 是裸直链(`http://…:19000/my-media/media/hls/{code}/index.m3u8`):

| 问题 | 后果 |
|------|------|
| 链接永久有效 | 用户付费看一次,复制链接后永远免费看 |
| 人人可用 | 链接发群里/贴到别站,所有人直接播,带宽给盗链者打工 |
| 无来源区分 | 站点 A 买的内容,站点 B 用户拿链接照样看,多租户隔离失效 |
| 无法撤销 | 链接流出后没有任何手段使其失效,除非删片 |

## M1 之后:四道锁

`play_url` 变为网关签名地址 `http://…:8006/hls/{code}/index.m3u8?e={exp}&s={site}&sig={hmac}`:

1. **会过期**(默认 4 小时,`play_gateway.token_ttl_sec`):分享出去的链接几小时后即死链;
   想再看必须回站内重新通过业务校验(付费/VIP)换新链接。
2. **不可伪造**:`sig = HMAC-SHA256(secret, code|site|exp)`,密钥只在服务端;
   改任何参数(换资产、续期)都是 403。
3. **真实地址隐藏**:播放器只见网关;ts 分片走 300 秒短时效预签名
   (`play.presign_expire_sec`),扒到的分片地址几分钟后作废。
4. **来源可追责**:每个链接携带 `s={site}`,为按站点统计/防盗链/计费提供依据。

## 边界(M1 明确不管的,留给 M2)

- 有效期内转发的链接仍可播(→ M2 Referer/IP 约束)
- 无播放统计、无按站点策略、无密钥轮换、无试看

## 相关配置

- 密钥两边必须一致:my_media `play_gateway.secret` ⇔ my_play `play.secret`
- my_media 未配置 `play_gateway.base_url` 时自动回退 MinIO 直链(平滑降级开关)
